# The Connective Logic
Risk is not static. It propagates. In a traditional GRC stack, a risk event happens in one system and stays there until a human notices, interprets, and manually escalates.

In Simplif-i, risk propagates automatically across every module it touches. The system understands organisational dependencies. You do not need to be the integration layer. The platform is.

### Injection Flows
1. **Contract Breach Detected**: Injects into GRC (control effectiveness downgrade) + PMO (dependency alert on linked projects) + M&A (deal health re-score if vendor is part of target operating model) + Dashboard (board-level signal change).
2. **Compliance Evidence Expires**: Injects into Training (competency gap alert) + Contracts (obligation-at-risk flag) + CoSec (board reporting trigger) + Dashboard (posture degradation).
3. **Vendor Privacy Score Drops**: Injects into Contracts (agreement review trigger) + GRC (third-party risk event) + PMO (project dependency alert) + AI Governance (AI risk re-score) + Dashboard (supply chain signal).
4. **Project Milestone Breached**: Injects into GRC (dependent control implementation delay) + Contracts (SLA breach risk on delivery commitments) + M&A (integration timeline degradation) + Dashboard (delivery velocity drop).
5. **Statutory Deadline Missed**: Injects into GRC (corporate governance control failure) + M&A (deal confidence downgrade) + Contracts (counterparty notification obligation) + Dashboard (board-level escalation).
6. **DD Finding Surfaces**: Injects into GRC (new control requirement) + Contracts (obligation mapping) + PMO (integration workstream creation) + CoSec (entity onboarding trigger) + Training (competency gap identification).
